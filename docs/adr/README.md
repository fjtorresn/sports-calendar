# Architecture Decision Records (ADRs)

Un ADR registra **una** decisión de arquitectura: el contexto, lo que se decidió y
sus consecuencias. No se reescriben: si una decisión cambia, se crea un ADR nuevo
que **reemplaza** al anterior, así queda la historia de por qué se cambió.

Formato basado en [Michael Nygard](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions).
Estados posibles: `Propuesto`, `Aceptado`, `Reemplazado por NNNN`.

Para crear uno nuevo: copiar el formato de un ADR existente y usar el siguiente número.
